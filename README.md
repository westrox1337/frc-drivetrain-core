# 🤖 FRC WPILib Drivetrain Core

A baseline Java implementation for FIRST Robotics Competition (FRC) robot drive systems, focusing on clean autonomous routines and teleop control logic.

## 🛠️ Features
- 🏎️️ **Drivetrain Baseline:** Structured control logic for differential robot motion.
- ⚙️ **Subsystem Initialization:** Clean setup routines for motor controllers and sensors.
- 🔄 **Periodic Loops:** Standard WPILib-style execution for autonomous and teleop modes.

## 🧰 Tech Stack
- **Language:** Java
- **Framework Concept:** WPILib / FRC Robotics

## 📦 How to Build & Run

1. Clone the repository:
git clone https://github.com/westrox1337/frc-drivetrain-core.git
cd frc-drivetrain-core

2. Compile the Java file:
javac Robot.java

3. Run the application:
java Robot
